# WhatsApp Workflow V1

- Added WhatsApp Center to the private workspace.
- Shows contacts with mobile numbers, priority leads, and today's follow-ups.
- Opens contextual prefilled WhatsApp messages for General, Property, and Coaching templates.
- Logs a `WhatsApp opened` activity on the customer record when the action is launched.
- Existing direct WhatsApp buttons now use the same contextual message logic.
- No WhatsApp Business API credentials or bulk automation are included in V1.
