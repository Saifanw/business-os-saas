# BusinessOS V20 — Notifications & Reminders

Added a dedicated Notifications Center using existing workspace data.

## Included
- Follow-up due/overdue notifications derived from customer next-action fields.
- New Website Lead notifications.
- Pending payment notifications from Deals.
- Recent Team Activity notifications from activities.
- All / Follow-ups / Website Leads / Payments / Team Activity filters.
- Unread/read state stored per workspace in browser localStorage.
- Mark all read and refresh actions.
- Notification counts and summary metrics.
- Navigation links added to core workspace pages.

No new Firestore collection/rules are required in V20. Existing data permissions are reused.
